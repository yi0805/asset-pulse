# AssetPulse

AssetPulse is a small industrial asset monitoring and alarm dashboard portfolio project. It will demonstrate practical full-stack engineering through asset management, alarm acknowledgement and resolution, operational summaries, and asset status history using synthetic industrial data.

**Target stack:** Angular 18+, TypeScript, HTML/CSS, C#, .NET 8, ASP.NET Core Web API, Entity Framework Core, Microsoft SQL Server 2022, Docker Compose, automated tests, Git/GitHub, and GitHub Actions CI.

```text
Angular frontend -> HTTP / JSON REST API -> ASP.NET Core .NET 8
                                                |
                                         Entity Framework Core
                                                |
                                      Microsoft SQL Server 2022
```
